WAYFARER is my final project for my UX / UI Engineering course under the BEAM Institute of Technology.

It is a webpage / app coded entirely by hand, with the purpose to provide an easy way for people to find their favored pastime destinations.

The webpage shows a brief introduction to itself, then directly brings the user to its main UI, where a location can be punched into a search bar.
Based on this, the page will bring up a map for the user, showing sightseeing locations in their selected range nearby.
Here, they have the option to further inform themselves by clicking on the results for a brief informational blurb, or, if they are registered and logged in, save the results for later.
There is also a suggestion segment, and the option to switch between light and dark mode.
